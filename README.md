# Matrix Game

Este proyecto es un juego inspirado en la película Matrix, desarrollado para la materia ARSW. El objetivo principal es que el jugador (Neo) navegue por una matriz, evitando obstáculos y alcanzando el objetivo (Target), mientras interactúa con agentes y paredes.

## Propósito
El juego busca poner en práctica conceptos de programación orientada a objetos, manejo de interfaces gráficas y lógica de juego en Java. Es ideal para aprender sobre estructuras de datos, algoritmos y diseño de software y también el manejo de los hilos y la concurrencia de este mismo.

## Ejecución

1. **Compilar el proyecto:**
   - Abre una terminal en la carpeta raíz del proyecto.
   - Ejecuta el siguiente comando para compilar usando Maven:
     ```powershell
     mvn clean package
     ```

2. **Ejecutar el juego:**
   - Una vez compilado, ejecuta el archivo principal con:
     ```powershell
     java -cp target/classes org.arsw.Main
     ```

## Requisitos
- Java 21 o superior
- Maven
